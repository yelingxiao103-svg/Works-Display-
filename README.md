# Works-Display- · 叶凌霄工业设计作品集

这是一个纯静态个人作品集网站，使用 HTML、CSS 和原生 JavaScript 编写，不需要 Node.js 或安装依赖。

## 本地预览

直接用浏览器打开 `index.html`。视频和图片使用相对路径，请保留 `assets/` 目录。

## Cloudflare Pages 设置

- Framework preset：`None`
- Build command：留空
- Build output directory：`.`（项目根目录）
- Root directory：留空
